# Retail Product Content & Shopping Assistant

An end-to-end deep learning system with four modules:

| Module | Task | Model |
|---|---|---|
| Image Classifier | Product image → category | ResNet18 / EfficientNet-B0 |
| Content Generator | Attributes → title/description | Flan-T5-small (fine-tuned) |
| Semantic Search | Natural-language → products | MiniLM + FAISS |
| Shopping Assistant | Conversational RAG chatbot | Retriever + Flan-T5 |

Served via **FastAPI** backend and **Streamlit** UI.

---

## Quick Start

```bash
# 1. Install
pip install -r requirements.txt
pip install -e .

# 2. Generate real dataset (downloads from HuggingFace, ~44K fashion products)
python scripts/prepare_dataset.py

# 3. Build search index
python -m train.build_index

# 4. Start API  →  http://127.0.0.1:8000/docs
uvicorn retail_assistant.api:app --reload --app-dir src

# 5. Start UI   →  http://localhost:8501
streamlit run app/streamlit_app.py
```

---

## Training

```bash
# Image classifier (ResNet18, with eval on test set)
python -m train.train_classifier --backbone resnet18

# Compare against EfficientNet-B0
python -m train.train_classifier --backbone efficientnet_b0

# Fine-tune Flan-T5 content generator
python -m train.finetune_content_gen
```

## Configuration

All paths and hyperparameters are in [`configs/config.yaml`](configs/config.yaml).
Key settings:

```yaml
seed: 42
classifier:
  backbone: resnet18     # or efficientnet_b0
  epochs: 10
  lr: 0.0003
embedder:
  use_faiss: true        # false → numpy fallback
generator:
  base_model: google/flan-t5-small
```

## Known Limitations

- **Template descriptions**: Flan-T5 training targets are template-generated from metadata attributes, limiting stylistic variety compared to human editorial copy.
- **Text-only retrieval**: Semantic search utilizes dense textual embedding representations; multimodal vision search (CLIP) was omitted to preserve low CPU latency.
- **CPU inference**: All models run on CPU; production scale would benefit from GPU acceleration and quantization (ONNX / TensorRT).
- See [REPORT.md](REPORT.md) for full limitations, ablations, and ethics discussion.
