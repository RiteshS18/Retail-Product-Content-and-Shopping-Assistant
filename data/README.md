# Data
`sample/products.csv` is synthetic (generated by `scripts/make_sample_data.py`) so the pipeline runs immediately.

For the real project use a public dataset, e.g.:
- Fashion Product Images (Kaggle)
- Amazon Berkeley Objects (ABO)
- Amazon Reviews 2023 metadata

Put images in `data/images/` and make sure `image_path` in the CSV points to files relative to that folder.
Required columns: `product_id,name,category,brand,color,price,attributes,description,image_path`.
